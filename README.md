# fabianwgl/homebrew-tap

Homebrew casks for [fabianwgl](https://github.com/fabianwgl) apps.

```sh
brew install --cask fabianwgl/tap/dvsk
```

| Cask | App |
|---|---|
| `dvsk` | [Dvsk](https://github.com/fabianwgl/dvsk), an open-source f.lux alternative for macOS |

Casks are updated automatically when a new release is published.
